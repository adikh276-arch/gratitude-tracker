# Gratitude Tracker

A simple and effective tool to track your daily gratitude and mood for better mental wellness.

## Features

- Daily gratitude entries
- Mood tracking
- Internationalization (i18n) support
- Multi-language interface

## Technologies Used

- Vite
- TypeScript
- React
- shadcn/ui
- Tailwind CSS
- i18next

## Getting Started

### Prerequisites

- Node.js (v20 or higher)
- npm

### Installation

1. Clone the repository:
   ```sh
   git clone <repository-url>
   ```

2. Navigate to the project directory:
   ```sh
   cd gratitude-tracker
   ```

3. Install dependencies:
   ```sh
   npm install
   ```

4. Start the development server:
   ```sh
   npm run dev
   ```
